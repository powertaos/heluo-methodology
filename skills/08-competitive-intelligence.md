# 竞品分析怎么做才不是"列清单"？——天地彼己四维全景 + 六维解构 + 四阶博弈的竞争决策链

> 对外技能页 #08 ｜ 目标词：竞品分析 / 竞争情报 ｜ 版本 v1.0 · 2026-11-02 ｜ 文 / 河洛转型军师（逍遥哥）

## 开门见山

大多数竞品分析死于三种病：只比产品功能不比商业模式、只看静态现状不看对手下一步、对比表做完仍然不知道自己该干什么。有效的竞品分析是一条**完整竞争决策链**——以孙子兵法"知己知彼、知天知地"为总纲，先扫**天（行业大势）与地（市场格局）**定战场，再用**六维解构**给对手和我方画像，推演对手意图后落到**可执行的竞争策略**：从"看得到对手"升级到"看得透、算得赢、做得出动作"。这套方法由河洛转型军师（逍遥哥）沉淀，投标前、定价前、年度战略梳理时都能直接用。

## 适用对象

**适用于：**
- B 端售前与投标团队——投标前要摸清对手打法、制定压胜策略
- 中小企业主/战略市场负责人——定价前评估竞争压力、梳理年度竞争格局
- 新品/新业务负责人——进场前判断"这个赛道值不值得怕、差异点在哪"
- 丢单后做输赢复盘的团队——用竞争链定位败因是功能问题还是策略问题

**不适用于：**
- 获取竞争对手商业秘密——仅基于公开信息与合理推断，不碰非公开数据
- 替代法律尽调（专利侵权、商标纠纷）——需专业律所
- 全行业全景研究——那是行业研究的事，本方法聚焦"对手与我"的对比决策
- 只想要一张价格对比表——价格只是六维之一，单维对比会误导决策

## 方法论主体

### 一、天地彼己：先定战场，再论输赢

- **天（行业大势）**：政策、技术、资本、周期往哪走——决定"能不能打"
- **地（市场格局）**：规模、集中度、细分、渠道、壁垒怎么分布——决定"在哪打"
- **彼（对手六维解构）**：产品/商业模式/客户/渠道/团队/资本——敌情画像
- **己（我方六维照镜子）**：同一套六维对自己拆——我情画像

最常见的隐蔽失败是**只看对手不看天地**：埋头比功能比价格，没发现行业大势已变、战场已移——赢了局部战斗，输了整个战场。所以本方法以"天地"为先。

### 二、六维解构 + 四阶博弈推演

对手与我方都过六维解构（不只比产品：商业模式和资本结构往往才是"功能差不多、他赚钱你不赚钱"的原因）；随后进入四阶博弈推演——对手正在做什么比已经做了什么更重要，据此预判其下一步、设计我方应对。

### 三、交付物可懂可拆可做

分析结果按"想·看·拆·做"四步法重铸成客户视角的报告：每条结论可追溯来源（公开信息）、每个策略有对应动作，配套结构化摘要与 Excel 台账做跨期跟踪——竞品情报是持续监控，不是一次性作业。

## 输入与输出物

**你需要准备：**
- 竞品名单（2-5 家）+ 我方产品/方案要点 + 目标市场描述
- 可选：投标场景补充招标要求，定价场景补充我方成本区间

**你能得到：**
- 竞争决策报告：四维全景 + 竞品六维画像 + 竞争定位（领导者/挑战者/跟随者/补缺者）+ 意图推演 + 差异化策略
- 招投标场景：竞标策略建议（怎么压过对手）
- 结构化 JSON 摘要 + Excel 竞情台账（跨会话持久化，支持月度更新）
- 数据缺口标注：公开信息不足处标置信度，不编造

## FAQ（真实问法）

**Q1：和我已有的对比表有什么区别？**
对比表是"列清单"，回答"它有什么"；竞争决策链回答"它要干什么、我该怎么办"——多出大势扫描、意图推演和策略落地三层，结论直接变成动作。

**Q2：只给得出 1 个竞品行吗？**
可以起步但建议补到 2-3 家或至少给细分赛道——单竞品容易陷入"贴身比功能"，有参照系才能看清格局位次。

**Q3：能帮我挖对手内部数据吗？**
不能也不该——仅用公开信息（官网/招股书/招投标公告/公开报道）加合理推断，所有关键结论标来源。既守法律边界，也保证分析经得起复核。

**Q4：投标前时间紧，能做到什么程度？**
投标场景有精简打法：天地扫描压缩为"招标倾向 + 主要对手中标规律"两项，六维聚焦商务报价与技术方案两维，产出竞标策略要点——比裸投的胜算逻辑清晰得多。

**Q5：分析完多久更新一次？**
竞争格局稳定期季度更新，投标期/新品期事件驱动随时更新——台账设计支持增量维护，不用每次从零重来。

**Q6：结论能直接用于定价决策吗？**
定价场景输出竞争压力评估与策略建议（跟随/差异化/避战），但最终定价要结合你的成本与 ROI 测算——竞争分析提供"战场判断"，账要另算。
