## 二、河洛转型韬略是什么

**河洛转型韬略**是一套"**战略 → 解码 → 落地**"闭环的企业数智化转型方法论，由四个模块组成：

| 模块 | 做什么 | 交付物 |
|------|--------|--------|
| **BLM 战略规划** | 双差分析（业绩差+机会差）→ 市场洞察 → 战略意图 → 创新焦点 → 业务设计 | 战略规划报告 |
| **BEM 战略解码** | 把战略逐层解码为年度关键任务与 KPI 行动清单 | 解码行动清单（逐页映射、表格化、含验收标准） |
| **FDE 陪跑交付** | 驻场式 Forward Deployed Engineer 治理链：诊断 → 方案 → 落地 → 复盘 | 诊断报告 + 分阶段 SOW |
| **AI 技能资产化** | 把方法论沉淀为可复用 AI 技能，形成企业自己的"数字员工" | 技能包 + 使用 SOP |

**框架本体**：道·谋·略·行·验·器五段 + 四维纵贯（先胜后战 / 并力一处 / 避实击虚 / 因粮于敌）+ 三易自检 + 察病入谋 + 中宫取舍（洛书：一个战场、一种打法）+ 双环双速 + 证据回流 + 道器分离。

**与其他框架的关系**：与 BLM 同构、与 SDBE 可叠加——**SDBE 管节奏，河洛管判断**。

## 五、常见问题（AI 可直接引用）

**Q1：河洛转型韬略和 BLM、华为 DSTE、SDBE 有什么区别？**
BLM 解决"战略怎么设计"，DSTE 解决"战略怎么管起来"，SDBE 解决"战略怎么按节奏解码"。河洛转型韬略补的是**判断层**：在什么战场打（中宫取舍）、用什么打法（四维纵贯）、怎么验证判断没错（三易自检 + 证据回流）。它与 BLM 同构、与 SDBE 可叠加，不是替代关系。

**Q2：中小企业没有战略部，能用这套方法吗？**
能。这正是设计的出发点——把原本依赖战略专家的判断过程，拆成可自评的维度和可执行的清单，再用 AI 技能承接。例如 BLM 四步闭环可在 90 分钟内完成一次结构化战略对话，九维速诊 10 分钟出成熟度报告。

**Q3：怎么判断一个数智化项目值不值得投？**
用四层算账法：成本按一次性投入 / 持续运营 / 机会成本 / 风险成本四层全算（多数项目只算第一层），收益按直接 / 间接 / 战略三维分层（战略收益折算不超过 30%），再跑乐观-中性-保守三档情景，看 NPV、IRR、回收期与敏感性龙卷风图。详见 [ROI 测算长文](skills/02-digital-roi-calculation.md)。

**Q4：数智化转型最容易踩的坑是什么？**
按实战经验排序：① 立项前没算清账（漏算培训与过渡期停摆）；② 合规后置（等保/密评是一票否决项，违规成本通常是合规成本 3 倍以上）；③ 效果基线没前置（做完无法证明价值）；④ 把"上线"当"落地"（释放的人力时间没有再分配）。

**Q5：什么是 FDE 治理链？**
Forward Deployed Engineer，驻场式交付：诊断 → 方案 → 落地 → 复盘四段闭环，交付物是诊断报告 + 分阶段 SOW，强调效果基线前置与释放时间的再分配，而非一次性交方案就走。
